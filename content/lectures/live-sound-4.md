## 🎤 Lecture: Live Sound Part 4 — Troubleshooting, Recording Feeds, and System Handoff

### Live Sound Part 4: Troubleshooting and Handoff

**Last week:** Build and line-check an organized system.

**This week:** Find faults, distinguish destinations, and leave the system usable for the next person.

### The Question for Today

When something is missing, distorted, too quiet, or in the wrong place: **Where does the signal path stop behaving as expected?**

Troubleshooting works best when you trace the path one stage at a time.

### Trace the Signal Path

A simple troubleshooting path:

Source → cable / DI → mixer input → preamp → channel → bus → output → amplifier → speaker

Ask at each stage:

- Is signal present?
- Is the level usable?
- Is it routed to the expected destination?
- Is this device powered and connected correctly?

### Three Different Kinds of "No Sound"

- **No Input Signal:** The source, cable, DI, mic input, phantom power, or gain stage has a problem.
- **Input Works, but Not in Main:** The channel level, mute/on state, bus assignment, Main master, or Main output path has a problem.
- **Main Works, but Monitor Does Not:** The Aux send, Aux master, Aux output cable, monitor input, or monitor power has a problem.

Each failure points to a different part of the system.

### PFL / Solo as a Troubleshooting Tool

PFL, Solo, AFL, and Cue vary by mixer.

Their shared purpose: Check a signal without depending on the room speakers.

Use them to answer:

- Does this input arrive at the mixer?
- Is the preamp clipping?
- Does the channel still contain audio when Main is silent?
- Is the problem before or after the fader?

### Fault Example: Guitar Missing From Main

The guitarist is playing. PFL shows usable signal. The monitor mix contains guitar. The audience cannot hear guitar.

Likely places to check:

- Channel mute/on state
- Channel level
- Main assignment
- Main bus/master level

The source and preamp probably work. Do not restart troubleshooting at the guitar.

### Fault Example: Singer Cannot Hear Themself

The singer is audible in Main L/R. The singer's monitor is silent.

Likely places to check:

- Lead-vocal Aux send
- Aux master/output level
- Aux output cable
- Powered monitor input and gain
- Monitor AC power

Main L/R working does not prove the monitor path works.

### Fault Example: Everything in the Monitor Is Too Quiet

The performer likes the balance. Every source is just too quiet.

The likely control is: **Aux master/output level**

Do not turn up every channel's Aux send if the relative mix is already correct.

### Main Mix, Monitor Mix, Stereo Board Feed, and Multitrack

| Destination | What it contains | Typical purpose |
|---|---|---|
| Main L/R | Audience mix | PA / house speakers |
| Aux / monitor bus | Performer-specific mix | Wedge or in-ear monitor |
| Stereo board feed | One finished stereo mix | Recording, stream, camera feed |
| Multitrack feed | Separate channels | Later mixing in a DAW |

A stereo board feed is not multitrack recording.

### Stereo Board Feed

A stereo board feed carries one mixed L/R signal.

Example: Mixer record output or assigned bus → recorder / camera / streaming interface

Before using it, ask:

- Does the receiving device expect mic or line level?
- Is the feed independent of Main L/R?
- Does it need its own level control?
- Is it actually stereo?
- Is the recording device receiving both left and right?

### Multitrack Feed

Multitrack recording sends channels separately.

Example:

- Lead vocal → recording channel 1
- Bass DI → recording channel 2
- Keyboard L/R → recording channels 3–4

A multitrack recording lets someone remix the performance later. A stereo board feed captures the mixer's decisions as they happen.

### Troubleshooting Sequence

When a problem appears:

1. Describe the symptom precisely.
2. Identify which destination is affected.
3. Check the simplest relevant controls first.
4. Use meters or PFL/Solo to locate signal.
5. Trace only the path that serves the failed destination.
6. Change one thing at a time.
7. Confirm the fix.
8. Record or label the issue if it may recur.

Randomly turning knobs is not troubleshooting.

### System Handoff

A good handoff answers:

- What mixer and speaker systems are in use?
- What goes to Main?
- What goes to each Aux/monitor?
- What channels are active?
- Are any special adapters, DI boxes, or power supplies involved?
- Are scenes, labels, or routing changes saved?
- What should the next engineer avoid touching?

A working system should remain understandable after its original operator leaves.

### Final Practice Goal

Given a small system with one planted fault:

1. Identify the failed destination.
2. Trace the relevant signal path.
3. Use PFL/metering where appropriate.
4. Fix only the actual problem.
5. Explain why the fix worked.
6. Restore the system cleanly.
