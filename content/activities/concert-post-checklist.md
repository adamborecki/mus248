## 🎬 What this is

The step-by-step for a multicam concert, from the synced multicam clip to the delivered files.
It assumes you already know the house rules (Background render off, **Leave files in place**,
H.264): those are on [Final Cut Pro at Chapman](../../fcp-at-chapman/), and the
[Post Mini](../../post-mini-1/) activities teach them.

**Before you start, know the delivery.** This checklist's example is three sections named
`Concert_Act_1` to `_3`. A Salmon recital is usually one file per piece instead (`01`, `02a`…,
see [Post Mini 3](../../post-mini-3/)). If nobody has told you which, ask.

## 🎥 Prepare the multicam clip

- 🚩 Create the multicam clip from the recorded camera angles and audio.
- 🚩 Drag the multicam clip into the project timeline.
- 🚩 Select **Lift from Storyline**.
- 🚩 Select **Add Custom**.
- 🚩 Refit the time to start, following the established project workflow.
- 🚩 Play the beginning and a few points throughout: audio and video are in sync.
- 🚩 The intended camera angles are present and usable.
- 🚩 The correct audio source is the one you hear.
- 🚩 No missing media, offline clips, or unexpected gaps.
- 🚩 Save the project.

## 🧹 Clean up the full concert

- 🚩 Select the project and open the three-arrow menu used in your workflow.
- 🚩 Delete the unwanted text or titles.
- 🚩 Review the full concert in the timeline.
- 🚩 Trim the empty space at the beginning, without cutting into the first performance.
- 🚩 Trim the empty space at the end, keeping the final performance and its applause.
- 🚩 Add a fade-out at the end.
- 🚩 Adjust the applause volume with audio keyframes as needed.
- 🚩 Transitions between performances feel natural.
- 🚩 No music, applause, or important announcement is cut off.
- 🚩 No sudden volume jumps, clipping, distortion, or unwanted noise.
- 🚩 The final fade is smooth and doesn't end abruptly.

## 📤 Export the full concert

- 🚩 Watch the concert once more: sync and levels are right, with no black frames, gaps, or unwanted clips.
- 🚩 Export the concert as video with audio: 1920 × 1080 unless the delivery says otherwise, the project's frame rate, H.264.
- 🚩 Audio is included in the video export.
- 🚩 Export a separate audio-only file in the required format (WAV unless told otherwise).
- 🚩 Name them clearly, for example `Concert_Full_Video` and `Concert_Full_Audio`.

## 📑 Duplicate the project for the sections

- 🚩 **Duplicate Project As** to copy the finished full-concert project.
- 🚩 Name the copy **Acts**.
- 🚩 The copy's format is 1080p (1920 × 1080).
- 🚩 The original full-concert project is unchanged. Every section edit happens in **Acts**.

The original is your clean master: if an edit has to be redone, you start again from it.

## ✂️ Divide the concert into sections

- 🚩 Find the start and end points of each section.
- 🚩 Divide the recording into the three sections: beginning, middle, and end.
- 🚩 Cut precisely with the **Blade** tool (B), zoomed in on the timeline.
- 🚩 Remove or separate footage that doesn't belong in each section.
- 🚩 Each section starts and ends where it should: no performance's beginning or end is cut off, and the applause has finished before the next section.
- 🚩 No unintended gaps between clips.
- 🚩 Play each section from beginning to end.

## 🎞️ Export the sections

- 🚩 Select the first section and set the export range to just that section.
- 🚩 Export it as video with its audio.
- 🚩 Repeat for the middle and end sections.
- 🚩 All three use the same resolution and frame rate.
- 🚩 Name them clearly, for example `Concert_Act_1`, `Concert_Act_2`, `Concert_Act_3`.

## ✅ Final quality control

- 🚩 The full concert video plays from beginning to end.
- 🚩 The audio-only file plays correctly.
- 🚩 Each section plays correctly.
- 🚩 Audio and video stay in sync in every file.
- 🚩 No missing media, black screens, or accidental gaps.
- 🚩 Every file has a clear name and is in the correct delivery folder.
- 🚩 The original full-concert project is preserved.

## ⚙️ Technical verification

**The guide's own items to confirm:**

- ❓ The exact menu location of **Lift from Storyline**, **Add Custom**, and the "three-arrow
  menu" in the Final Cut version on the lab computers. Post Mini 3 has a similar sequence ("Lift
  from Storyline, Custom generator, & Replace with Retime to Fit"): confirm it's the same, and
  write the clicks here.
- ❓ The required audio-only format (WAV, AIFF, MP3, or another).
- ❓ Whether the sections are delivered as three exports, three separate projects, or both. This
  page assumes one **Acts** project with three exports.

**Where it differs from other pages, flagged rather than resolved:**

- ❓ **"Delete the unwanted text or titles" from the three-arrow menu.** Possibly the same as Post
  Mini's "set the metadata title to **Recording** and delete all other metadata." Confirm.
- ❓ **Sections vs. pieces.** This guide splits a concert into three acts; the Post Mini slides
  and Lifespan of a Recording deliver one file per piece (and per movement), with two-digit
  numbers. Which gigs get which?
- ❓ **Full-concert edits.** This guide trims and fades the full concert. Lifespan of a Recording's
  old-manual notes say the complete concert file is never edited and keeps everything, walk-on to
  applause. Both may be right for different deliveries; confirm.
- ❓ **H.264** is from the house rules, not this guide (which says only "1080p" and "the original
  frame rate"). It's the course default.
