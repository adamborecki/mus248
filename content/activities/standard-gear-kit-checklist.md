## 🎚️ What this is

The field checklist for a gig recorded with the **Standard Gear Kit** — the portable rig you
carry to a venue: a stereo pair into a **Zoom F8**, a **Zoom H4n** as backup audio, and two
**Sony AX100** cameras. Every line is something you do or check.

**Recording in Memorial Hall?** Run the [Memorial Hall Gig Checklist](../../memorial-gig-checklist/)
alongside this one — its F8 input layout (boundary mics, board feed) replaces the
**Connections** and **F8 configuration** steps here. Pack up with the
[Standard Gear Kit Reset](../../standard-gear-kit-reset/).

## 🧰 Equipment and materials

The full list is the separate **Required Materials** checklist. Everything the steps below call
for:

- [ ] **Telescoping mic stand**, **stereo bar**, and **two mic clips**
- [ ] **Two pencil condenser mics** (cardioid)
- [ ] **Two XLR cables** for the mics — two more if there's a board feed
- [ ] **Velcro** ties
- [ ] **Zoom F8**, its **AC power**, and batteries (backup only)
- [ ] A clean **32 GB SD card** for the F8
- [ ] **Zoom H4n Pro** (or similar), **freshly charged batteries**, and a clean **8 GB SD card**
- [ ] **Lighting stand** with a **¼-inch screw** for the H4n
- [ ] **Two Sony AX100s**, each with the **correct tripod plate**
- [ ] **Two tripods**
- [ ] Two clean **128 GB SD cards** — one per camera
- [ ] **Charged batteries or AC power** for both cameras

## 🚗 Phase 1 — Before arrival

- 🚩 Gather all required materials — see the separate **Required Materials** checklist.

**Q1 (short answer).** Call time: ______ · Concert: ______ · Venue: ______ · Arrival time: ______

✅ **Answer.** There's no fixed answer — write in tonight's call time, concert, venue, and when
you actually got there. It's a log entry, not a test.

## 🙋 Phase 2 — On arrival: the things that need other people

Other people's time is the bottleneck — do these first.

- 🚩 Ask house staff for **concert lighting** — the brightest lighting level used during the
  actual performance — so camera exposure can be set correctly.
- 🚩 If the concert involves electronics, ask about a **board feed** — a copy of the signal going
  to the main speakers.
- 🚩 Re-order the rest of this checklist around those answers. If the lights won't be ready for a
  while, do audio first.

## 🎙️ Main recording rig — Zoom F8

**Mic stand and stereo bar**

- 🚩 Set up the **telescoping mic stand**.
- 🚩 Attach the **stereo bar** and the **mic clips** to the top.
- 🚩 Mount the **pencil condenser mics** (cardioid) in **ORTF** or **NOS**. NOS is usually easier.

**Cable management**

- 🚩 Run the XLRs gently from each mic, and wrap each **once around the stereo bar**.
- 🚩 Secure with **Velcro** at the top, so the mics can't move.
- 🚩 Route the cables neatly down the stand, lined up with the tightening notches.
- 🚩 Keep it clean — this stand may be in the video.

**Connections**

- 🚩 **Left mic → Input 1** on the F8.
- 🚩 **Right mic → Input 2** on the F8.
- 🚩 Board feed, if there is one → **Inputs 3 and 4**.

**Power and media**

- 🚩 Insert batteries — for **backup only**.
- 🚩 Plug in **AC power** for the concert.
- 🚩 Insert the clean **32 GB** SD card.

**F8 configuration**

- 🚩 Turn on **Dual Channel Recording**: **Menu → REC → Dual Channel Recording**.
  - Main mic pair: **1 → 5**, **2 → 6**.
  - Board feed, if used: **3 → 7**, **4 → 8**.
- 🚩 Set starting gain, then adjust for the ensemble's volume, the mics' sensitivity, and the
  distance:

| Channels | Starting gain |
|---|---|
| 1–2 (main pair) | **≈ 42 dB** |
| 5–6 (dual-channel copy) | **≈ 30 dB** |

- 🚩 Use the **PFL** buttons to check each channel's signal and adjust its gain.
- 🚩 From the same PFL screen, turn on **phantom power** where the condensers need it.

**Q2 (multiple choice).** With Dual Channel Recording on, which channel holds the second copy of
the **right** mic?

- a) Channel 2
- b) Channel 5
- ✅ c) Channel 6
- d) Channel 8

**Q3 (fill in the blank).** Starting gain on the F8: channels 1–2 ≈ ______ dB · channels 5–6 ≈
______ dB.

✅ **Answer.** Channels 1–2 ≈ **42 dB**; channels 5–6 ≈ **30 dB**. Both are starting points —
adjust for the ensemble, the mics, and the distance.

## 🎧 Backup audio — Zoom H4n

- 🚩 Mount the **Zoom H4n Pro** (or similar) on the lighting stand with the **¼-inch screw**.
- 🚩 Insert **freshly charged batteries**.
- 🚩 Insert the clean **8 GB** SD card.
- 🚩 Signal check: have a performer play their **loudest passage**, and set the input so it's
  neither clipping nor too quiet.

## 💡 Lighting

- 🚩 Ask for **concert lighting** — the brightest setting used in the performance.
- 🚩 **Don't set exposure until concert lighting is on.** The pre-show look is often much darker.

**Q4 (multiple choice).** When do you set the cameras' exposure?

- a) As soon as you arrive, so it's done early
- b) Under the pre-show lighting, since that's what's on when you're ready
- ✅ c) Once concert lighting — the brightest level used in the performance — is on
- d) At intermission

## 🎥 Cameras — Sony AX100s

**Mounting**

- 🚩 Confirm the **correct plate** is on each camera.
- 🚩 Mount each camera securely on its tripod.
- 🚩 Extend the tripods tall enough to clear the audience's heads.

**Camera configuration**

- 🚩 **White balance:** set **both** cameras to **Indoor** — they have to match.
- 🚩 Start from the default exposure:

| Setting | Default |
|---|---|
| f-stop | **f/4.0** |
| Gain | **3 dB** |
| Shutter | **1/60 sec** |

- 🚩 **Too dark?** Change the shutter to **1/30**, and set the f-stop **as low as it will go**
  with the framing you need (not too far zoomed out, not too far zoomed in). Still too dark?
  Raise gain to **+6 dB** or higher.
- 🚩 **Too bright?** Raise the f-stop: f/4 → f/5.6 → f/8.

**Media and power**

- 🚩 Insert a clean **128 GB** SD card in each camera.
- 🚩 Charged batteries or AC power on both.

**Framing and leveling**

- 🚩 Confirm each camera is **level** — no rotation!
- 🚩 Frame slightly wide: every performer in, without a lot of empty space.
- 🚩 Double-check that the two cameras cover what they're meant to — e.g., one wide, one close.

**Q5 (multiple choice).** Under concert lighting, the picture is too **bright** at the default
exposure. What do you change first?

- a) Gain, up to +6 dB
- b) Shutter, to 1/30
- ✅ c) The f-stop, up — f/4 to f/5.6
- d) White balance, to Outdoor

**Q6 (short answer).** Under concert lighting, the picture is too **dark** at the default
exposure. List the fixes in the order you try them.

✅ **Answer.** First, shutter to **1/30** and the f-stop **as low as it will go** for your framing.
If it's still too dark, raise gain to **+6 dB** or higher.

**Q7 (fill in the blank).** SD cards: Zoom F8 ______ GB · Zoom H4n ______ GB · each AX100 ______
GB.

✅ **Answer.** F8 **32 GB** · H4n **8 GB** · each AX100 **128 GB**.

## ✅ Definition of done

- 🚩 The stereo pair is on Inputs 1–2, with Dual Channel Recording to 5–6, and every channel's
  signal checked with PFL.
- 🚩 The F8 is on AC power, with a clean 32 GB card in.
- 🚩 The H4n is mounted, signal-checked on the loudest passage, with a clean 8 GB card in.
- 🚩 Both AX100s are on matching white balance, exposed under concert lighting, level, and framed
  to cover what they're meant to.
