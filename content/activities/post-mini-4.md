## 🎯 What you'll practice

A **recording session** in Salmon instead of a concert: the performer plays each piece, or each
part of it, several times, and you deliver every take as its own file. There's no complete
concert file and no program. Your map is the **take notes**.

## 🗝️ Key terms

**take** · **takes vs. files** · **take notes** · **false start** · **incomplete take** ·
**normalize**

| Term | What it means |
|---|---|
| **Take** | One attempt at recording a piece or a section of it. |
| **Takes vs. files** | Usually one video file per take, but the slides say "usually." Count both, so you notice when they don't match. |
| **Take notes** | The engineer's running log of each take: what it was, and how it went. The performer can add comments after. |
| **False start** | A take stopped in the first few seconds. |
| **Incomplete take** | A take stopped partway through. |
| **Normalize** | A Logic bounce option that turns the whole file up to a set peak. We want it **off**. |

## 🧰 Ingredients

- 4K video files, usually one per take.
- A backup video camera? (The slides leave it as a question: check what's in the folder.)
- The primary audio, as a Logic project.
- A backup audio recorder's files.
- Take notes, instead of a program.

## 📦 Deliverables

- **No** 4K complete concert file.
- **One video file per take,** numbered with two digits: `01`, `02`, `03`, `04`.
- **One more file per movement,** lettered: `02a`, `02b`, `02c`.
- **Overall:** decently loud, and a little brighter exposure.
- **Each file:** video with no fade-in and a short fade-out only. Audio: listen for a click at
  the beginning (there won't be one, but check), and fade out if necessary.

## 🗂️ The job, in order

Everything from Phases 1–3 still applies: data management, Logic setup, the Final Cut settings,
**Leave files in place** (and the `x` renames), project settings, the multicam clip, global
fixes, and **edit the pieces first, then audio and fades, then split by movement.** What's new:

1. **Logic: check Normalize in the bounce's output settings.** We want it **off**.
2. **Listen to the backup audio,** even if you don't need it. Make sure it's acceptable. If it
   isn't, report the problem.
3. **Final Cut: check the Active Audio Angle and Active Video Angle** on every take.
4. **Moving the end of a fade:** tap **T**, drag the dissolve, then tap **A**.
5. **Get around faster:** **J** back, **K** pause, **L** forward (tap J or L twice to go faster);
   **↑** and **↓** jump between edits; **⇧ ⌘ B** cuts.
6. **Share the master file as H.264,** and check the project settings once more first: 1080p, and
   the metadata.

🚩 You have the same number of audio files as video files, or you know why not.

## 🎤 On the session itself

Phase 4 is post, but the slides also cover what makes the post easy, back when you were recording.

**Tell the performer before you start:**

- Leave some silence after each take.
- The engineer keeps take notes; they can add comments afterwards.
- Every file will be delivered.
- Single takes only: no editing between files.
- Ask whether they need it by a particular deadline.

**While you record:**

- Always have backup recorders.
- Start and stop all the recorders at the same time, so there are as many audio files as video files.
- Stay positive and encouraging, and help the performer feel relaxed.
- On a freelance gig, discuss payment well ahead of time, don't charge too little, and make clear
  that special requests are billed separately.

## ✅ Definition of done

- 🚩 One video file per take, numbered `01`, `02`, `03`, plus one per movement, lettered `02a`, `02b`, and so on.
- 🚩 No complete concert file.
- 🚩 Decently loud, and a little brighter than the raw footage.
- 🚩 Every file: no video fade-in and a short video fade-out; an audio fade-out if needed.
- 🚩 Logic's Normalize was off for the bounce.
- 🚩 You listened to the backup audio and reported it if it wasn't acceptable.

## 💭 Before you leave

**Q1 (multiple choice).** How is a recording session's delivery different from a recital's?

- a) It's the same: a complete concert file plus one file per piece
- ✅ b) No complete concert file; one file per take, plus one per movement
- c) Only the best take is delivered
- d) All the takes are joined into one file

**Q2 (fill in the blank).** In Logic's bounce settings, **Normalize** should be ______.

✅ **Answer.** Off.

**Q3 (short answer).** You didn't need the backup audio. Why listen to it anyway?

✅ **Answer.** To make sure it's acceptable: it's the safety net for every future session, and if
it isn't working, the problem has to be reported before it's needed for real.

**Q4 (multiple choice).** There are 14 video files and 12 audio files. What most likely happened
on the session?

- a) Two takes had no sound
- ✅ b) The recorders weren't always started and stopped at the same time
- c) Final Cut lost two files on import
- d) That's normal; audio files are always fewer

**Q5 (multiple choice).** The performer asks you to splice the best half of take 3 with the best
half of take 5. What did the slides say to tell them before the session?

- a) That's included in every session
- ✅ b) Single takes only, no editing between files; special requests are a separate job (and billed separately on a freelance gig)
- c) It can only be done in Final Cut, not Logic
- d) Takes can't be delivered as separate files
