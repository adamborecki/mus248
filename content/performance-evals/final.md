Like the midterm: you show specific skills, one station at a time, by yourself. The goal is that
everyone who passes MUS 248 can work the normal gig types, not that you specialize early.

## 🧭 How it works

1. Every station is required.
2. Same procedure as the midterm: one handwritten notecard per station (front and back OK), phone
   and laptop locked up, the printed sheet, a timer, and you do it by yourself.
3. A checker watches and checks your work.
4. Retakes are allowed if there's time, but not if you put a station off until the end.
5. Already ran the Salmon Gig Checklist for real? It doesn't count here: the Salmon station is
   tested on its own.
6. Each station ends the way a gig does: everything put back the way you found it. (Planned; to
   be confirmed.)

## 🎬 Salmon A/V Recording and Livestream

**Goal:** Run the default Salmon gig: A/V recording with a livestream.

📖 [Salmon Gig Checklist](../../salmon-gig-checklist/) · [Salmon: Livestream](../../salmon-livestream/)

> **Where and when:** a mock setup in Salmon, during class time on one of four dates in November.

> **How the test runs:** like a real gig, in four parts: audio, video, livestream, and downstairs.
> The recordings are tiny on purpose: each recorder rolls for only a few seconds, so the files
> stay small and the cards go straight into the SD card reader for the data transfer. The
> livestream part is questions only: you open Vimeo, but nobody creates a test stream.

> **Practice with the answer key.** It's the same sheet with every answer filled in. The real test
> uses the sheet without them.

### 🎙️ Audio recording

- [ ] Battery backup on ✅ a single tap on the power button
- [ ] Zoom F8 on ✅ the switch at the lower right, held about 2 seconds (a quick tap does nothing)
- [ ] Zoom H6 on ✅ hold the switch on the left
- [ ] Says which card size goes in the backup recorder (Zoom H6) ✅ 8 GB
- [ ] Says which card size goes in the Zoom F8 ✅ 32 GB
- [ ] A clean card in each recorder ✅ the F8's slot is on its far left side
- [ ] Headphones on: clean signal on both recorders ✅ checks the F8 and the H6; left and right are different, not one signal doubled
- [ ] F8 preamps: looks, doesn't touch ✅ all set the same; one that looks off gets reported, not adjusted
- [ ] All 8 F8 channels record-enabled ✅ a red light under each one
- [ ] A 5–6 second test recording on both the F8 and the H6 ✅ the counters actually moving on both, not just a button pressed
- [ ] Stops both recorders ✅ on the F8, the STOP button, not the red record button
- [ ] Both cards out and into the SD card reader
- [ ] Powers off what they turned on ✅ the F8 needs the same 2-second hold to turn off

### 🎥 Video recording

- [ ] Powers on the video system
- [ ] The fast card into the HyperDeck ✅ the Lexar Professional 128 GB card, in the top-left slot
- [ ] Starts a recording and stops it after about 2 seconds ✅ the counter actually moving
- [ ] Center wide camera: zooms out, then in ✅ zoom in RovoControl
- [ ] Center wide camera: pans left, then right ✅ the joystick
- [ ] Center wide camera: tilts up, then down ✅ the joystick; gain and f-stop left alone
- [ ] How wide should the shot be? ✅ wide enough for everyone on stage, with room to bow at the end, but not crazy wide; zoom in a little when the instrumentation changes

### 📡 Livestream

- [ ] Opens the Vimeo page ✅ on the livestream computer; normally already signed in (top right). No test event.
- [ ] Which streaming service do we use right now? ✅ Vimeo
- [ ] Once the event is set up, what do you need from the streaming service? ✅ the stream key
- [ ] Where does the stream key go? ✅ ATEM Software Control
- [ ] What do you copy from Vimeo for the audience? ✅ the embed code
- [ ] Where does the embed code go? ✅ the livestream page in Canvas
- [ ] How do you actually start streaming? ✅ stream key in ATEM Software Control, then On Air
