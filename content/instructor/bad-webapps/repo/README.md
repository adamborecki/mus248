# 🙃 Bad Webapps

Tiny webapps that are **bad on purpose**, and bad in a way that's actually good. A metronome that
slowly drifts. A tuner that insults you. A mirror that's two seconds late.

Built by students practicing **vibecoding**: describing an app to an AI, testing what it makes,
and iterating, within a small prompt budget.

**See them all:** the live site is this repo on GitHub Pages (the link in the repo's **About**
box).

## Add yours

Read **[CONTRIBUTING.md](CONTRIBUTING.md)**. It walks through every click, all in the browser.

In short: fork → paste **[STARTER.md](STARTER.md)** into your AI → build → add
`apps/your-app-name/index.html` to your fork → open a pull request.

## The rules

- **One app, one folder:** `apps/your-app-name/index.html`, everything in that one file.
- **Bad on purpose, but it has to work.** A tuner that insults you still has to listen.
- **No real names**, yours or anyone's. Your GitHub username is enough.
- **Nothing creepy:** apps that use the mic or camera never record, save, or send anything.
- **No outside scripts, fonts, or trackers.** One self-contained file.

The instructor reviews and merges every pull request.
