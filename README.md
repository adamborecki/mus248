# MUS 248 Activities

A public, static activity directory for MUS 248: AV Concert Recording.

Canvas remains the place for enrollment, submissions, discussions, grades, and authentication. This site may link to Canvas but contains no student journals, student work, identifying information, or copied Canvas content.

## Content

- `content/activities/` — reusable activity Markdown
- `data/activities.json` — directory metadata used by the site
- `data/semesters/` — term-specific Canvas links and end-of-activity reminders
- `index.html`, `app.js`, and `styles.css` — the static site for GitHub Pages

`content/activities/_template.md` defines the standard activity frontmatter and sections. An activity may be a complete Markdown activity, a legacy item that points to an external document, or a placeholder for an activity not yet migrated.

## Current scope

The initial directory mirrors the Fall 2026 Canvas discussion ecosystem. Its cards intentionally identify the source as Canvas-linked until the reusable instructions are migrated into Markdown.

## Privacy

Do not add student journals, student names, personal drive links, submissions, grades, or other identifying information to this repository.
